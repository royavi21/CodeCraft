# CodeCraft — Scanner & Generator Suite

🌐 **Live Demo:** https://royavi21.github.io/QR_Code_Generator/

CodeCraft is a modern all-in-one QR Code and Barcode Generator web application built with HTML, CSS, and JavaScript. It provides multiple code-generation tools within a clean, responsive, and user-friendly interface.

---

## Features

### QR Code Generator

Generate custom QR codes with advanced customization options.

#### Supported Features

* Generate QR codes from URLs or text
* Adjustable QR code size (128px–512px)
* Custom foreground and background colors
* Error correction levels:

  * Low (7%)
  * Medium (15%)
  * Quality (25%)
  * High (30%)
* Live preview while typing
* Download as PNG
* Download as SVG
* Copy QR Code Data URL
* QR metadata display
* Custom styling support

---

### Barcode Generator

Generate industry-standard barcodes for digital and print use.

#### Supported Barcode Formats

* CODE128
* EAN-13
* UPC-A
* CODE39
* ITF-14
* MSI
* Pharmacode

#### Customization Options

* Adjustable bar width
* Adjustable height
* Show or hide value text
* Custom barcode color
* Custom background color
* Live generation preview

#### Export Options

* Download as PNG
* Download as SVG

---

### vCard QR Generator

Create professional contact-sharing QR codes.

#### Personal Information

* First Name
* Last Name
* Phone Number
* Email Address

#### Work Information

* Organization
* Job Title
* Work Address

#### Social & Web Information

* Website URL
* LinkedIn Profile
* Notes/Bio

#### Export Options

* Download QR Code as PNG
* Download Contact as .VCF file

---

### WiFi QR Generator

Allow users to connect to WiFi instantly by scanning a QR code.

#### Features

* SSID (Network Name)
* Password Support
* Security Types:

  * WPA/WPA2
  * WEP
  * Open Network
* Hidden Network Support
* One-scan WiFi connection
* Download QR as PNG
* Copy QR Data

---

### Text & URL QR Generator

Convert any text or URL into a QR code.

#### Features

* Multi-line text support
* URL support
* Live character counter
* Adjustable QR size
* Custom foreground color
* PNG download support

---

### Email QR Generator

Generate QR codes that open a pre-filled email.

#### Features

* Recipient Email
* Subject
* Email Body
* Instant QR generation
* PNG download support

---

### SMS QR Generator

Generate QR codes for pre-filled SMS messages.

#### Features

* Phone Number
* Message Content
* Instant QR generation
* PNG download support

---

### Phone QR Generator

Create QR codes for instant calling.

#### Supported Types

* Phone Call
* FaceTime

#### Features

* Direct dialing support
* PNG download support

---

### History System

#### Features

* WiFi QR history
* Text QR history
* Email QR history
* SMS QR history
* Phone QR history
* Preview generated items
* Re-download generated items
* Clear history option
